# Contributing Guidelines

Thank you for your interest in contributing to this project.

This is a **private project**, and contributions are allowed only with prior authorization.

## Contribution Flow
1. Fork or clone the repository (if authorized)
2. Create a branch following the pattern:
    - feature/feature-name
    - fix/bug-description
3. Commit with clear and descriptive messages
4. Open a Pull Request for review

## Code Standards
- Follow Laravel best practices
- Use PSR-12 coding standards
- Keep commits small and focused
- Avoid breaking existing features

## Reviews
All contributions must be reviewed before merging.
